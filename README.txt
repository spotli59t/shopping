LITTLE MARKET — интерактивная игра

ЗАПУСК
1. Полностью распакуйте ZIP.
2. Откройте index.html в браузере. Интернет для самой игры не нужен.
3. Для GitHub загрузите index.html, style.css, script.js и папку images в корень репозитория. Не загружайте ZIP вместо распакованных файлов.
4. Игра готова для размещения через GitHub Pages. README.txt загружать необязательно.

ПРАВИЛА
В каждом раунде — 8 разных позиций с количеством словами.
Слева — изображения товаров и цены за одну штуку или упаковку.
Перетащите товар в корзину или нажмите на его картинку. Одно действие добавляет одну штуку / упаковку. Картинка на полке остаётся.
Кнопка − в корзине убирает одну единицу.
Check my basket проверяет состав и количество. Галочки показывают верные позиции; восклицательные знаки — количество, которое нужно исправить.
После правильного сбора открывается подсчёт стоимости. Итог скрыт до правильного ответа.
Введите сумму в фунтах, например 13.55 или 13,55. Число попыток не ограничено.
New shopping list создаёт новый набор и очищает корзину. Если покупки уже есть, игра просит подтвердить смену раунда.
На узком экране список располагается над продуктами, корзина — ниже. Удобнее добавлять продукты нажатием.

КАРТИНКИ
В images — 21 продукт, shop-background.png и basket.png.
Имена файлов менять нельзя без изменения кода.
Цены учебные, в британских фунтах; актуальные магазинные цены они не отражают.

РЕДАКТИРОВАНИЕ
В начале script.js находится PRODUCTS. Число после названия файла — цена в пенсах: 150 = £1.50.
Следующие две строки в записи — название одной покупки и форма для нескольких.
Никаких внешних библиотек, аккаунтов, сервера или сбора данных нет.

ПРОВЕРКИ
Проверены: 1000 случайных списков (8 уникальных товаров, количества 1–3), расчёты в целых пенсах, проверка недостающих и лишних покупок, ввод суммы.
В браузере проверены загрузка изображений, перетаскивание мышью, добавление нажатием, удаление, проверка корзины, неправильная и правильная сумма, новый раунд.
Сенсорное устройство отдельно не тестировалось; предусмотрено добавление нажатием.
